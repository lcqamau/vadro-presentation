# ✈️ Vadro - Générateur d'itinéraires intelligents

> 🔒 **Note :** Le code source de cette application est actuellement privé (Closed Source) pour des raisons de propriété intellectuelle. Ce dépôt sert de présentation de l'architecture et des fonctionnalités du projet.

### 🎯 Le Concept
Vadro est une application complète (Fullstack) conçue pour révolutionner l'organisation de voyages quotidiens. L'objectif est de fournir aux utilisateurs des itinéraires optimisés et personnalisés, générés dynamiquement.

### 🧠 Les défis techniques relevés
En tant que Lead Developer sur ce projet, j'ai dû résoudre plusieurs problématiques d'ingénierie :
1. **Optimisation des requêtes SQL :** Garantir un temps de réponse très court, même avec une base de données contenant des milliers de points d'intérêts.
2. **Architecture API :** Sécurisation des flux de données entre l'application mobile et le serveur.
3. **UX/UI :** Rendre la manipulation de données complexes (itinéraires, cartes, horaires) simple et intuitive pour l'utilisateur final.
